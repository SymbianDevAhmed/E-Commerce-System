## 📌 About the Project

The **E-Commerce System** is a Java console application developed as a diploma assignment to practice Java fundamentals and Object-Oriented Programming (OOP) concepts.

The application simulates a basic online shopping experience, allowing customers to browse products, manage their shopping carts, place orders, and manage order statuses.

---

## ✨ Key Features

- 📦 **Product Display:** View available products, including electronics and clothing.
- 🛒 **Shopping Cart:** Add products, view cart contents, update quantities, and remove products.
- 💰 **Discount Calculation:** Apply product-specific discounts.
- 🧾 **Checkout:** Place orders based on shopping cart contents.
- 📊 **Stock Management:** Update product stock after checkout.
- 📋 **Order History:** View previously placed orders.
- 🚚 **Order Status Management:** Manage order statuses throughout the order lifecycle.
- ⚠️ **Exception Handling:** Handle invalid operations and common errors.

---

## 🧠 OOP Concepts Applied

| Concept | Description |
|---|---|
| **Encapsulation** | Organizing data within classes and controlling access through methods. |
| **Inheritance** | Extending the abstract `Product` class to create specialized product types. |
| **Abstraction** | Defining common product behavior through an abstract class. |
| **Polymorphism** | Supporting product-specific discount calculations. |
| **Enum** | Representing order statuses using `OrderStatus`. |

## ▶️ How to Run

### Prerequisites

- Java Development Kit (JDK) 21
- IntelliJ IDEA
- Maven

### Steps

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Configure the Project SDK to use JDK 21.
4. Reload the Maven project.
5. Locate and run `Main.java`.
